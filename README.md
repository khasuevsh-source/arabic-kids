# Учим арабский — площадка для детей

Простой сайт без сервера: мультики с двойными субтитрами, алфавит, слова, игры и домашка.
Результаты домашки уходят в Google-таблицу учителя.

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/` | Сам сайт — эту папку публикуем (GitHub Pages) |
| `docs/data/class.js` | Ученики, домашние задания, адрес Google-таблицы — **редактирует учитель** |
| `docs/data/videos.js` | Мультики с субтитрами, переводом и словариком |
| `docs/data/words.js` | Слова по темам |
| `docs/data/alphabet.js` | Алфавит |
| `google-sheet/` | Скрипт для Google-таблицы и инструкция `НАСТРОЙКА.md` |
| `tools/transcribe.py` | Распознавание арабской речи (Whisper) для новых мультиков |

## Посмотреть сайт на компьютере

```
python -m http.server 8090 --directory docs
```

и открыть http://localhost:8090

## Личная ссылка ученика

`https://<адрес сайта>/?kid=<код из class.js>` — сайт запоминает ученика на устройстве.
